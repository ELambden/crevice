# Community

## Questions and discussion

Ask usage questions, discuss methods or share analyses in the repository's
[GitHub Discussions](https://github.com/ELambden/crevice/discussions). Use
[issues](https://github.com/ELambden/crevice/issues) for reproducible bugs and
concrete feature requests.

## Reporting problems

Open an issue at <https://github.com/ELambden/crevice/issues>. A helpful report includes the
CREVICE version, the exact command or script, the input (an accession, or a
small shareable file) and the relevant `*_manifest.json` or input report. For
numerical questions, also include the settings you varied. For a scientific
disagreement, such as a cavity that looks wrong, give the independent reference
you are comparing against.
