# Citing CREVICE

A paper describing CREVICE is in preparation:

> Lambden, E., Findlay, H. and Booth, P. J. *CREVICE: Analysis and
> Visualisation of Protein Cavities, Channels, and Residue Interaction
> Networks.* In preparation.

Until it is published, please cite the software itself using the metadata in
[CITATION.cff](../../CITATION.cff) (GitHub shows it as "Cite this repository"),
and give the CREVICE version you used. Report the exact commands and settings
as well, because CREVICE's geometric results depend on grid spacing, probe radii
and atom selection.

CREVICE builds on ideas from HOLE, HOLLOW, CAVER and 3V, and uses MDAnalysis for
trajectory input and periodic distance calculations. Please also cite the tools
and methods your analysis relies on. The method notes give primary references
for each approach.
