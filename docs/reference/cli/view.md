# crevice view

Write a single, self-contained HTML file that shows an output directory in 3D
in a web browser: the protein cartoon, the cast surfaces, lining residues, the
profile centre line and member waters, each with a checkbox. The file works
offline (3Dmol.js is inlined) unless you choose `--cdn`. In Jupyter, use
{func}`crevice.view` instead. For a walk-through, see
[Explore results interactively](../../examples/explore-interactively.md).

```{crevice-cli} view
```
