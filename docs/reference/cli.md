# Command-line reference

This page is generated from `crevice.cli.build_parser()` each time the site is
built, so it always matches the code the site was built from. Each
[tool page](../tools/index.md) repeats the options for its own command next to
the method description.

The `crevice` executable and `python -m crevice` run the same parser.

```{argparse}
:module: crevice.cli
:func: build_parser
:prog: crevice
```
