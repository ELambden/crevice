Module index
============

Every ``crevice`` submodule is listed here and documented from its docstrings.
A build check (``docs/_ext/crevice_docs.py``) fails the documentation build if a
submodule is added to or removed from the package without updating this list.

Many modules are internal building blocks. The supported entry points are
summarised in the :doc:`Python API <index>`. ``crevice.__main__`` (which runs the
CLI on import) is deliberately excluded.
